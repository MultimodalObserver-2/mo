# Multimodal Observer (MO)

**Multimodal Observer (MO)** is an open-source, cross-platform desktop application designed to streamline the process of working with multimodal data sources. Built with modularity and extensibility in mind, MO allows users to integrate and manage diverse data capture sources in a unified environment.

The application supports plugin-based extensions, making it flexible and adaptable to a wide variety of data processing and visualization needs. It is developed with a modern architecture that separates the frontend (UI) and backend (API), each with its own setup and development workflow.

## 🔧 Project Structure

This repository is structured into multiple components. Please refer to the individual README files for setup and development instructions:

- [`ui/README.md`](./ui/README.md) – Setup, usage, and build instructions for the **Electron + React UI**.
- [`api/README.md`](./api/README.md) – Setup and development instructions for the **API backend**.
